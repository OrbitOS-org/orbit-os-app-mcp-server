Setup Steps
  1. Open Cursor and go to Settings → MCP, or create .cursor/mcp.json in your project root
  2. Copy the JSON config above and paste it (merge with existing content if the file already exists)
  3. Reload the MCP server list in Cursor (or restart Cursor)
  4. The orbit-os server should appear as connected — you can now ask Cursor about your device
